AA23 WEBSITE — QUICK SETUP

1. Keep the folder structure exactly as it is.
2. Put your MP4 movie video in the video folder and name it:
   aa23-background.mp4
3. Open index.html to test locally, or upload the entire folder to your web host.
4. The PNG background and logo are already included in assets/.

The video is displayed with object-fit: contain so its original aspect ratio is preserved on mobile and desktop. The intro button starts playback; a sound toggle is provided because some browsers restrict autoplay with sound.
